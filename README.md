# Railway World Model

JEPA/V-JEPA2-inspired research project for offline railway video and train-state prediction.

Safety boundary: this repository is for research and simulation only. It must not be used to control real trains or safety-critical systems.

## Layout
- `app/`: training entry points
- `configs/`: experiment configuration files
- `evals/`: evaluation entry points
- `src/`: datasets, models, masks, and shared utilities
- `scripts/slurm/`: remote GPU-cluster job scripts
- `tests/`: automated checks

## Status
Only the project skeleton exists. Do not add proprietary or sensitive railway data to this repository.
